\## 🔍 Investigation Summary

In this investigation, I analyzed a network packet capture (`.pcap`) involving suspicious network activity linked to the \*\*TA505\*\* threat group and the \*\*MirrorBlast\*\* malware campaign.



\### Key Objectives Completed:

\- \*\*Alert Triage:\*\* Examined network logs using \*\*Brim\*\* (Zui) and \*\*Wireshark\*\* to filter relevant traffic.

\- \*\*Threat Intelligence:\*\* Utilized \*\*VirusTotal\*\* and external threat feeds to enrich IPs, domain hashes, and malicious payloads.

\- \*\*C2 Identification:\*\* Located Command and Control (C2) servers, malicious file paths, and execution strings used during the intrusion.

\- \*\*Incident Documentation:\*\* Detailed the infection vector, payload attributes, and IOCs (Indicators of Compromise).
