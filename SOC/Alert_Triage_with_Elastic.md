\# Alert Triage with Elastic



\## Overview



Completed a hands-on SOC investigation using Elastic (Kibana) to triage security alerts and investigate suspicious activity across Windows and IIS environments.



\## Key Activities



\- Investigated web attack alerts

\- Analysed Windows account activity

\- Investigated suspicious command execution

\- Correlated events across multiple log sources

\- Identified indicators of compromise (IOCs)

\- Reconstructed attacker activity using Kibana



\## Tools \& Concepts



\- Elastic Stack (ELK)

\- Kibana

\- Alert Triage

\- Log Correlation

\- Windows Event Logs

\- IIS Logs

\- IOC Analysis

\- Threat Investigation

\- Incident Response



\## Key Takeaway



Practised using Kibana to investigate security alerts, correlate log events, identify indicators of compromise, and support SOC incident investigations.
