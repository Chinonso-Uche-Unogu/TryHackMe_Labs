# Network Traffic Basics – TryHackMe

## Overview
Completed the **Network Traffic Basics** room on TryHackMe. This lab teaches core network traffic analysis skills using packet capture (PCAP) files and network traffic inspection — a critical skill in SOC and incident response roles.

## Key Concepts Learned
- How to use **Wireshark** to analyze network traffic
- Understanding of packet structures and protocols (TCP, UDP, ICMP)
- Identification of common attack traffic patterns
- Filtering PCAP data to find suspicious activity
- Insight into how attackers communicate and how defenders detect it

## SOC Relevance
Network traffic analysis is a core SOC capability because:
- Attack behaviors often leave traces in network traffic
- Detection engineers rely on traffic patterns to create alerts
- Incident responders use PCAP for root cause analysis
- Threat hunters look for anomalous connections and beaconing
