# Detecting Web Shells – TryHackMe

## Overview
Completed the Detecting Web Shells room on TryHackMe. This lab focused on identifying malicious web shells through log analysis, file system investigation, and network traffic analysis.

## Skills Practiced
- Web shell detection
- Log analysis and investigation
- Network traffic monitoring
- File system analysis
- Threat hunting techniques

## Key Concepts Learned
- Understanding how attackers deploy web shells
- Detecting suspicious HTTP GET and POST requests
- Identifying malicious query strings and user agents
- Detecting file uploads and suspicious PHP files
- Investigating attacker activity through logs and PCAP analysis

## Tools & Technologies
- Wireshark
- Linux CLI
- Apache/Nginx logs
- PCAP analysis
- Audit logs

## SOC Relevance
Web shells are commonly used by attackers for persistence and remote access. Detecting them quickly is essential for SOC analysts and incident responders to prevent further compromise and lateral movement.
