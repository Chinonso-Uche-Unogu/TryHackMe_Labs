# Wireshark Packet Operations – TryHackMe

## Overview
Completed the **Wireshark Packet Operations** room on TryHackMe, a hands-on lab focused on packet capture and traffic inspection using Wireshark. This session develops the ability to analyze network activity down to individual packets — an essential skill for SOC analysts and incident responders working with live traffic or PCAP files.

## Key Concepts Learned
- Use of **Wireshark filters** to isolate traffic of interest  
- Understanding TCP/UDP packet fields and structure  
- Identifying normal vs suspicious network behavior  
- Analyzing flows to detect handshake anomalies  
- Extracting files and payloads from packet captures  

## SOC Relevance
Network packet analysis is core to:
- Identifying command & control traffic  
- Detecting lateral movement patterns  
- Investigating malware communication  
- Validating IDS/IPS alerts and SIEM correlations
