# Detecting Web DDoS – TryHackMe

## Overview
Completed the Detecting Web DDoS room on TryHackMe. This lab focused on identifying and analyzing Denial-of-Service (DoS) and Distributed Denial-of-Service (DDoS) attacks using web logs, SIEM analysis, and network investigation.

## Skills Practiced
- Detecting DoS and DDoS attacks
- Web log analysis
- SIEM-based investigation
- Identifying malicious traffic patterns
- Incident response fundamentals

## Key Concepts Learned
- Difference between DoS and DDoS attacks
- Understanding botnets and attacker motives
- Detecting spikes in HTTP requests
- Identifying suspicious IP addresses and user agents
- Mitigation and defense strategies for DDoS attacks

## Tools & Technologies
- SIEM platforms
- Web server logs
- HTTP traffic analysis
- Network monitoring tools

## SOC Relevance
DDoS attacks can disrupt business operations and impact service availability. SOC analysts must quickly identify malicious traffic patterns, investigate suspicious activity, and support mitigation efforts to reduce downtime and operational risk.
