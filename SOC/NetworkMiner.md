# NetworkMiner – TryHackMe Lab

## Overview
NetworkMiner is a Network Forensic Analysis Tool (NFAT) used to analyze PCAP files and extract artifacts from captured network traffic.

## Skills Practiced
- Network Forensics
- PCAP Analysis
- Host and Session Identification
- File Extraction from Network Traffic
- Protocol Investigation

## Key Concepts Learned
- Using NetworkMiner for offline traffic analysis
- Identifying hosts, IP addresses, and sessions
- Extracting transferred files and credentials
- Understanding network artifacts during investigations

## Tools Used
- NetworkMiner
- PCAP files
- Traffic analysis techniques

## SOC Relevance
NetworkMiner helps SOC analysts quickly identify suspicious hosts, extracted files, and communication patterns during network investigations.
