# Wireshark Traffic Analysis – TryHackMe

## Overview
Completed the **Wireshark Traffic Analysis** room on TryHackMe, focused on analyzing packet captures (PCAPs) to identify network traffic patterns, anomalies, and potential threats. This lab reinforces skills in network traffic inspection and interpretation using Wireshark — an essential tool for SOC analysts and incident responders.

## Key Concepts Learned
- Use of **Wireshark filters** to isolate specific traffic  
- Identification of protocol types (TCP, UDP, ICMP, DNS, HTTP, etc.)  
- Recognizing normal vs suspicious traffic behavior  
- Analyzing handshake sequences and connection patterns  
- Detection of beaconing and malicious network communications

## SOC Relevance
Network traffic analysis is a core competency for:
- Detecting command and control (C2) communication  
- Investigating malware activity  
- Validating SIEM alerts involving network indicators  
- Conducting forensic network investigations
