# Network Discovery & Detection – TryHackMe

## Overview
Completed the Network Discovery & Detection room on TryHackMe. The lab focuses on identifying network reconnaissance activities performed by attackers and learning how SOC analysts detect scanning behavior in logs.

## Skills Practiced
- Network reconnaissance detection
- Log analysis
- Identifying scanning activity
- Security monitoring

## Key Concepts Learned
- External vs Internal network scanning
- Horizontal vs Vertical port scanning
- Ping sweep detection
- TCP SYN scanning techniques
- UDP scanning behavior

## Tools & Technologies
- Firewall logs
- Zeek logs
- Kibana SIEM interface
- Network traffic analysis

## SOC Relevance
Network discovery is often the **first stage of an attack**. Detecting reconnaissance activity early allows SOC analysts to stop attackers before they gain access to internal systems.
