# Snort IDS/IPS – TryHackMe

## Overview
Completed the Snort room on TryHackMe. This lab focuses on using Snort, an open-source Intrusion Detection and Prevention System (IDS/IPS), to monitor, analyze, and detect malicious network activity.

## Skills Practiced
- Intrusion detection and prevention
- Writing Snort rules
- Network traffic analysis
- Log analysis and alert investigation

## Key Concepts Learned
- IDS vs IPS functionality
- Signature-based detection
- Snort rule structure (action, protocol, IP, port, options)
- Detecting suspicious traffic using custom rules

## Tools & Technologies
- Snort IDS/IPS
- Linux CLI
- PCAP analysis
- Network traffic monitoring

## SOC Relevance
Snort is widely used in SOC environments to detect and prevent attacks. Understanding how to write and analyze rules is essential for identifying threats and responding to incidents.
