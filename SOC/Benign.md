\# Benign



\## Overview



Completed a hands-on SOC investigation using Splunk to analyse Windows process creation logs and identify malicious activity on a compromised host.



\## Key Activities



\- Investigated Windows Event ID 4688 (Process Creation) logs

\- Identified suspicious process execution

\- Analysed attacker commands and process relationships

\- Correlated events to reconstruct the attack timeline

\- Investigated indicators of compromise (IOCs)

\- Determined attacker activity using Splunk searches



\## Tools \& Concepts



\- Splunk

\- Windows Event Logs

\- Event ID 4688

\- Process Creation Analysis

\- Log Correlation

\- IOC Analysis

\- Threat Hunting

\- Incident Response



\## Key Takeaway



Practised investigating a compromised Windows endpoint by analysing process creation logs, identifying malicious behaviour, and reconstructing attacker activity using Splunk.
