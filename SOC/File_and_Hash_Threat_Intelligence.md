\# File \& Hash Threat Intelligence – TryHackMe



\## Overview

Completed the File \& Hash Threat Intelligence room on TryHackMe. This lab introduced how file hashes are used to identify, verify, and investigate potentially malicious files using threat intelligence sources.



\## Key Concepts Learned

\- File hashing fundamentals (MD5, SHA1, SHA256)

\- Hash reputation lookups

\- Threat intelligence platforms

\- Indicators of Compromise (IOCs)

\- File integrity verification

\- Malware identification using hashes



\## Tools \& Technologies

\- PowerShell Get-FileHash

\- VirusTotal

\- Threat intelligence databases

\- SHA256 hashing



\## SOC Relevance

Hash analysis enables SOC analysts to quickly determine whether a file is known to be malicious, support malware investigations, and validate file integrity during incident response.
