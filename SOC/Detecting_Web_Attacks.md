# Detecting Web Attacks – TryHackMe

## Overview
Completed the Detecting Web Attacks room on TryHackMe. This lab focused on identifying malicious web activity through log analysis and recognizing common web attack patterns.

## Skills Practiced
- Web log analysis
- Detecting malicious HTTP requests
- Identifying web attack indicators
- Security event investigation

## Key Concepts Learned
- Detecting SQL injection attempts
- Identifying Cross-Site Scripting (XSS) activity
- Recognizing directory traversal attacks
- Analyzing suspicious HTTP methods and user agents
- Investigating web server logs for indicators of compromise

## Tools & Technologies
- Web server logs
- HTTP traffic analysis
- SIEM and log investigation techniques

## SOC Relevance
Web applications are frequent attack targets. Detecting web attacks early helps SOC analysts prevent compromise, protect sensitive data, and respond to threats effectively.
