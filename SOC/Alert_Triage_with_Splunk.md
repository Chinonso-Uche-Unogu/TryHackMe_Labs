\# Alert Triage with Splunk



\## Overview



Completed a hands-on SOC investigation using Splunk to triage and analyse security alerts across multiple attack scenarios.



\## Key Activities



\- Investigated initial access alerts

\- Analysed Linux brute-force attack activity

\- Investigated Windows persistence mechanisms

\- Analysed web shell activity on a compromised server

\- Correlated events using Splunk searches

\- Identified attacker behaviour and reconstructed attack timelines



\## Tools \& Concepts



\- Splunk SIEM

\- Alert Triage

\- Log Analysis

\- Event Correlation

\- Linux Authentication Logs

\- Windows Event Logs

\- Web Shell Detection

\- Threat Investigation

\- Incident Response



\## Key Takeaway



Practised using Splunk to investigate and triage security alerts, correlate events across multiple log sources, and identify attacker activity during real-world SOC investigation scenarios.
