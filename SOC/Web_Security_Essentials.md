# Web Security Essentials – TryHackMe

## Overview
Completed the Web Security Essentials room on TryHackMe. This lab provides a foundational understanding of how web applications work, common web-based attacks, and how to secure web infrastructure.

## Skills Practiced
- Web application security fundamentals
- Understanding HTTP request/response cycle
- Identifying common web vulnerabilities
- Applying defense-in-depth strategies

## Key Concepts Learned
- Web infrastructure (Application, Web Server, Host Machine)
- Common web threats and attack vectors
- Secure coding practices and input validation
- Web Application Firewall (WAF) and CDN protection
- Logging and monitoring for web security

## Tools & Technologies
- Web servers (Apache, Nginx, IIS)
- Web Application Firewall (WAF)
- CDN and logging systems

## SOC Relevance
Web applications are a primary attack vector. SOC analysts must monitor logs, detect suspicious web activity, and respond to web-based threats to prevent breaches.
