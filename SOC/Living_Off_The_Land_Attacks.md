\# Living Off the Land Attacks – TryHackMe



\## Overview

Completed the Living Off the Land Attacks room on TryHackMe. This lab focused on how attackers abuse legitimate system tools and utilities to evade detection and carry out malicious activities.



\## Key Concepts Learned

\- Living Off the Land (LotL) techniques

\- Abuse of legitimate system tools

\- Detection of suspicious command execution

\- Indicators of Compromise (IOCs)

\- Threat hunting strategies

\- Adversary behavior analysis



\## Tools \& Technologies

\- Native Windows and Linux utilities

\- Log analysis

\- Threat hunting concepts

\- MITRE ATT\&CK techniques



\## SOC Relevance

Understanding LotL attacks helps SOC analysts detect stealthy adversary activity that may bypass traditional security controls by using trusted system tools.
