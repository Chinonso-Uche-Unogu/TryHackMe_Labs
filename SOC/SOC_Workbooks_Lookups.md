# SOC Workbooks – Lookups (TryHackMe)

## Overview
This room teaches how to use SOC workbooks for analyzing alerts, performing lookups, and investigating security events.

## Skills Learned
- Alert correlation and triage
- Log lookups and enrichment
- Security monitoring workflow
- Incident response documentation

## Tools Used
- SIEM (Security Information and Event Management)
- Log analysis tools
- SOC dashboards

## Lessons Learned
- How to perform log lookups efficiently  
- How to prioritize and investigate alerts  
- Understanding the SOC workflow in a professional environment
