\# TryHackMe: Boogeyman 2



\## Overview



Completed a digital forensics investigation involving a phishing attack against Quick Logistics LLC.



This investigation focused on analysing a malicious email campaign, identifying the attack chain, investigating malware activity, and uncovering indicators of compromise.



\## Skills Demonstrated



\- Phishing email analysis

\- Malicious attachment investigation

\- VBA macro analysis using OleVBA

\- Windows memory forensics using Volatility 3

\- Process tree analysis

\- Detection of persistence mechanisms

\- Identifying Command and Control (C2) communication



\## Tools Used



\- Volatility 3

\- OleVBA

\- Email header analysis

\- Windows forensic artefact analysis

\- CyberChef



\## Key Techniques



\- Threat hunting

\- Incident response workflow

\- Malware behaviour analysis

\- Indicator of Compromise (IOC) identification

\- MITRE ATT\&CK mapping



\## Investigation Focus



The investigation involved analysing a phishing email containing a malicious document, extracting evidence from forensic artefacts, identifying attacker techniques, and understanding the malware execution chain.



\## Outcome



Successfully identified the attack methods, analysed malicious behaviour, and documented findings following a SOC/DFIR investigation workflow.
