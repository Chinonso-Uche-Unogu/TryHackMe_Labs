\## Key Learning Points



\### AMSI (Antimalware Scan Interface)



AMSI is a Windows security feature that allows antivirus and endpoint security solutions to inspect scripts and commands before execution.



\### PowerShell Security



PowerShell is widely used by administrators but is also abused by attackers. Understanding PowerShell execution flow helps defenders identify suspicious behavior.



\### Detection Evasion



Attackers may attempt to avoid detection by:

\- Obfuscating commands

\- Modifying scripts

\- Using memory-based execution techniques

\- Abusing trusted Windows components
