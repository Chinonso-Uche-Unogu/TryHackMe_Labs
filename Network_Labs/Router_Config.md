\# Cisco Router Network Configuration Lab



\## Overview

Configured a Cisco 1941 router using Cisco Packet Tracer to establish network connectivity between two separate LAN interfaces.



\## Device

\- Cisco 1941 Router

\- Cisco IOS 15.1



\## Configuration



\### Interface G0/0

IP Address:

192.168.1.1



Subnet Mask:

255.255.255.0



Status:

UP





\### Interface G0/1

IP Address:

192.168.2.1



Subnet Mask:

255.255.255.0



Status:

UP





\## Verification



Commands used:



show ip interface brief



copy running-config startup-config
